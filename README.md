## Классы

**UiHandler**  
Управляет интерфейсом для клиента и сервера.

- В режиме сервера: показывает панель сервера и добавляет кнопке отправки сообщений обработчик.
- В режиме клиента: показывает панель клиента с кнопками «Подписаться» / «Отписаться», обновляет их состояние и выводит полученные сообщения в текстовое поле лога.

---

**MessageHandler**  
Обрабатывает сетевые сообщения (например, HelloMessage, SubscribeMessage).

Служит связующим звеном между UI и сетевой логикой.

---

**MessageNetworkManager**  
Расширяет стандартный NetworkManager из Mirror для реализации системы publish‑subscribe.

Позволяет отправить сообщение (SendHelloMessageToSubscribers) только тем клиентам, которые подписались на соответствующий тип сообщения.

---

**SubscribeManager**  
Основное хранилище подписок на сервере.

Ведёт словарь, где ключ — имя типа сообщения, значение — набор подключений клиентов.

Позволяет клиентам подписываться или отписываться от конкретных типов сообщений.
